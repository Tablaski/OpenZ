# OpenZ-VK AI Maps

The package includes the converted maps used by the game, including scenes, native
layouts, decoded grids, minimaps, previews and shared materials. It references the
installed OpenZ base assets and is loaded directly by the Unity project.

Converted maps use V5 by default. Use `-oz-ai-maps-v4` or `-oz-ai-maps-v3` to select
an earlier terrain profile. `-oz-ai-arctic-legacy-snow` restores the procedural
snow on Arctic V5. The active catalog keeps its native routes and bridge rules.

The map authoring and preview generation tools are maintained in a separate repository.
